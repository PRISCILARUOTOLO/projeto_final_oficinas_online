📌 Como funciona este mural?

Nesta versão, o feedback é preparado para envio por e-mail ou pode ser copiado. As mensagens não aparecem publicamente para outros alunos. Para criar um fórum compartilhado de verdade, com publicações visíveis e moderação, é necessário conectar uma plataforma externa. A professora pode configurar o e-mail no arquivo main.js.
